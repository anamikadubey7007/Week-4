# My Cafe - Week 4

## Task
Enhancing Web Page Performance and Accessibility

## Files
- `index.html` - accessible semantic webpage
- `style.css` - responsive and optimized CSS
- `Week4_Performance_Accessibility_Report.md` - detailed report

## Improvements
- Semantic HTML
- Skip-to-content link
- Keyboard focus styles
- Accessible form labels
- Useful ARIA attributes
- Decorative icons hidden from screen readers
- Responsive mobile layout
- Reduced-motion support
- No external libraries or fonts
- Reusable CSS classes

## How to Run
Open `index.html` in a browser.

## Testing
Use Lighthouse, WAVE and Axe, plus manual keyboard navigation.
